# Workflow

Promise lifecycle:

Extracted -> Needs review -> Matched -> Gap detected -> Sales clarification needed / Product review needed / Engineering estimate needed -> Approved or Rejected -> Customer clarification sent -> Resolved -> Archived.

Every high-risk promise should have owner, status, due date, next action, evidence, and human review.

Product owns capability truth. Sales owns customer clarification. Engineering owns effort estimates. Customer Success owns onboarding impact.
