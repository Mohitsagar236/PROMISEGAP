# Product Spec

PromiseGap extracts customer promises from B2B SaaS documents, matches them to product capabilities, scores risk, and routes high-risk commitments through human review.

Core users: Product Managers, Technical PMs, Sales Engineers, Customer Success, Implementation Managers, Solution Architects, and founders.

Core objects: Account, Document, ExtractedPromise, Capability, PromiseCapabilityMatch, PromiseRiskScore, ActionItem, Report, RiskSetting.

MVP modules: auth, dashboard, account risk, document ingestion, extraction, capability catalogue, matching, scoring, workflow, reports, settings, and case study.
